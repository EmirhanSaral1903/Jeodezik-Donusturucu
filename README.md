# Geodesic Angle Converter

A single-page web application for converting geodetic angles across multiple units (Decimal Degree, Grad, Radian, NATO Mil, DMS). It includes automated calculations for surveying and mapping operations.

**Live Demo:** (https://jeodezik-donusturucu.vercel.app/)

**Features:**
* Real-time bidirectional conversion between Degree, Grad, Radian, Mil, and DMS.
* Geodetic calculations: Bearing, Deflection Angle, Zenith, Hour Angle, and Earth Arc Length (R≈6371 km).
* UI controls: Dark mode, decimal precision selector, calculation history, and keyboard shortcuts (Esc to clear).
* Error handling to prevent crashes from invalid inputs.

**Tech Stack:**
* HTML, CSS, Vanilla JavaScript
* Deployed via Vercel

**Usage:**
Input a numerical value into any unit field. All other unit fields and the advanced statistics panel will compute automatically based on the selected precision.
